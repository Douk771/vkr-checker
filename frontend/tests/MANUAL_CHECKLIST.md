# Ручной чек-лист фронтенда (F-16)

Playwright не согласован; e2e пишет qa-engineer. Запуск: `npm run mock` + `npm run dev` (мок) или бэкенд, раздающий `frontend/` с корня.
Для каждого пункта: консоль браузера без ошибок.

1. Старт: индикатор загрузки; при недоступном backend - ошибка и «Повторить».
2. Пароль: неверный (сообщение), 429 (Retry-After), успешный вход.
3. Баннер «LibreOffice не найден» при `layout_available=false`.
4. Проверка .docx: drag&drop и выбор файла; отмена во время запроса; 413/415/422.
5. Отчёт на golden `check_clean`, `check_findings`, `check_layout_failed`: фильтры, «Пройденные правила», «≈ стр.» только при layout ok.
6. XSS: в цитате/сообщении `</script><img src=x onerror=alert(1)>` - не выполняется на странице и в скачанном .html.
7. Скачанный отчёт открывается офлайн (без сети), совпадает с экраном.
8. Матрица MAT-01: статусы, пробелы с кандидатами, «Скачать .xlsx», пустая матрица.
9. Сравнение: diff над отчётом new, пустой diff, переносы по `move_id`, маркеры [+ +] / [− −] без цвета.
10. Печать (Ctrl+P) и навигация Tab: фокус виден.
